# Cinematic Video Editor Portfolio

A premium, immersive portfolio website built with Next.js, React, TypeScript, and Tailwind CSS.

## Stack
- Next.js (App Router)
- React + TypeScript
- Tailwind CSS
- Framer Motion + GSAP
- Three.js via @react-three/fiber and @react-three/drei

## Local development
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Notes
- Hero and project videos currently use external placeholder reels (Coverr CDN). Replace them with your own hosted assets for production.
- Typography is defined in `app/globals.css` using serif + sans-serif fallback stacks.
